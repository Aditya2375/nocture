# NOCTURE — slow light for dark rooms

A concept candle atelier: dark, cinematic storefront where every product sits
in a lit alcove and opens into a full-screen scene.

**Live:** https://nocture-ten.vercel.app

## Stack

Plain HTML, CSS and JavaScript — no build step, no framework.
Type: Italiana, Cormorant Garamond, IBM Plex Mono (Google Fonts).

## Run

Open `index.html`, or serve the folder with any static server.

## Notes

- A concept store: the products shown are fictional.
- Photography: Unsplash (hero, collection and atmosphere imagery).
